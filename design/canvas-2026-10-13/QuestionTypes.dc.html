Spec: T3
This is the catalogue behind the "+ Add question" picker in T2, shown the way each subject meets it. Pick a subject on top and the list becomes what a professor of that subject sees: first the types used most in their field, then the other types their packs allow, then a note on what is hidden (the superadmin chooses the packs; see A1, to be designed in more depth later). Each type lists what the teacher fills in, what the student sees (the sketch uses that subject's own example), how it is graded, which integrity signals it adds, and where it runs. A student's exam belongs to one course, so its questions come from one subject's list: a Biology exam never contains an editor, a Math exam never a listening clip. Status badges: DKU OJ means DKU OJ has an equivalent type; Lib means built in the standalone question library (not merged into the main app yet, not run on a Mac); New means not built anywhere. The "typical exam" bar is my illustration of how each field tends to mix types, to be checked with real professors. Add to an exam jumps to T2 with the type pre-chosen.
