## Notes on non-CONFIRMED and understated items

**CA-3 (confirmed, understated).** The reviewer only described attaching another course's contest. The ModelMultipleChoiceField takes any contest PK, and adding a class to `contest.classes` changes access control. Members of the attacker's class gain access, and the attacker becomes a "course teacher" of the contest through `linked_organization_ids()`. If the victim contest was org-wide (no classes), it becomes class-only, so the victim course's own students lose access. Severity should be High.

**CA-6 (partly).** Hidden exam (MCQ) results are not exposed through `participation.score`: the exam format scores hidden problems as 0 until finalize. What is exposed is final scores of ended contests regardless of `scoreboard_visibility`, including "Hidden permanently", which is the homework default. Only users who can already see the contest get them. `/api/v2/users?organization=` gives NetIDs and points (no real names). It is unauthenticated but the same as upstream DMOJ.

**AUTH-02 (partly).** The endpoint is behind a per-problem opt-in flag (`view_test_cases`, default off). Where enabled, it ignores exam masking and contest state as claimed. Severity Medium, not High.

**AUTH-04 (confirmed, understated).** `problem_types_json` is the more dangerous sink. ProblemType rows can be created by any instructor through a JSON endpoint, and the payload runs for every user who opens the add-problem page.

**AUTH-07 (partly).** The harness is served only when the author enabled "allow downloading tester file". The finding is really "no problem-access check on an opt-in download", which leaks across courses or before an exam. Low.

**SEB-2 (partly).** The code fact is correct, but ordinary class TAs and instructors (Class.admins) do not bypass. Only course admins (Organization.admins, including the course creator) do, and only on org-private contests. Students cannot become tester, spectator or org admin on their own. The real residual risk is a mistakenly added spectator, who can join live and skip SEB.

**G-2 nuance.** AI fill-blank falls back to exact-match grading when AI is not callable for that submission, so the result is not always 0. Short-answer becomes 0 (IR, or IE in batch mode).
